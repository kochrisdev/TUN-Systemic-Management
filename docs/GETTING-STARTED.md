# Getting started

[Documentation index](README.md) · [Worked example](../examples/ai-support-initiative.md)

You can apply this draft manually. No installation is required to use the templates.

1. **Choose one bounded initiative.** Name the people it should help, a human owner, and the decision you need to make. Start with a scope whose evidence and consequences can be understood.
2. **Write the outcome and alternatives.** Complete the [initiative charter](../templates/initiative-charter.md). Record the baseline or a plan to establish it, uncertainty, resource ceilings, and stop conditions.
3. **Make the initial decision.** Use the [decision record](../templates/decision-record.md) to document the selected option, authority, subject revision, evidence, dissent, and next review condition.
4. **Define the mandate and delegation.** State responsibilities and permitted actions separately. Identify the enforcement owner, data access, targets, limits, expiry, and intervention path. A completed template does not activate a tool or permission.
5. **Collect relevant observations.** Use explicit metric definitions, observation windows, and evidence references. Keep missing, contradictory, and unresolved results visible.
6. **Review and adapt.** Complete the [review record](../templates/review-record.md). Decide what changes, who owns each follow-up, and when to review again. Confirm operational control results separately.

Read the [specification](SPECIFICATION-v0.1.md) and [conformance matrix](CONFORMANCE-MATRIX.md) when assessing the workflow. Mark requirements unassessed until actual evidence and reviewer judgment support a result.

The [pilot plan](PILOT.md) describes future software work. There is currently no install command, running service, or executable management schema.
